# 🥭 Mango Mini OS

> A futuristic, glass-morphism web-based operating system dashboard built from scratch using vanilla HTML5, CSS3, and JavaScript.

## 🌟 Features

- **Futuristic HUD Design:** Sleek dark-mode glassmorphism aesthetic with neon cyan accents and backdrop blur effects.
- **Live System Clock:** Real-time digital clock updating every second in the HUD header.
- **Interactive Calculator:** Fully functional math engine built right into a glass card widget.
- **Persistent Notepad:** Built-in notes app that automatically saves your thoughts using the browser's `localStorage`.
- **Floating Dock:** Modern, animated bottom dock for quick app navigation with smooth hover transitions.

🚀 Getting Started
To run this project locally on your machine, follow these simple steps:

Prerequisites
Make sure you have VS Code installed along with the Live Server extension.

Installation & Running
Clone or download this repository to your local machine:

Bash
git clone [https://github.com/your-username/mango-mini-os.git](https://github.com/your-username/mango-mini-os.git)
Open the project folder in VS Code:

Bash
code mango-mini-os
Open index.html.

Right-click anywhere in the editor and select "Open with Live Server", or click the Go Live button in the bottom-right status bar of VS Code.

💡 How It Was Built
HTML5: Used semantic container <div> elements to structure the widgets, header, and floating dock.

CSS3: Leveraged modern CSS features including Flexbox, CSS Grid, radial gradients, and backdrop-filter: blur() for the frosted glass look.

Vanilla JavaScript: Wrote custom event listeners, setInterval timers for the clock, eval() math handling, and the Web Storage API (localStorage) for data persistence.
